# pet-with-you 1.0.1

Windows 10/11 x64 桌宠。下载 **pet-with-you-1.0.1-x64-setup.exe**，双击安装；纯桌宠无需另装 Node.js、Git 或 Codex CLI。

## 本次更新

- **改善 GPT 连接**：补上 Windows 系统静态代理向 Codex 子进程的传递，保留用户显式指定的代理。维护者已分别验证 config 密钥与 Codex 套餐碎碎念可用。
- **改善回复速度**：优先使用当前模型支持的最低推理强度，减少不必要的会话准备；不更换模型、不改变客户端任务，可在设置中关闭快速回复。实际速度仍取决于模型、服务商和网络。
- **更柔和的流式文字**：普通文字聊天逐步显示；减少碎碎念刷新卡顿，新文字增加约 0.42 秒淡入，支持选中复制与系统减少动态效果。
- **更清楚的错误反馈**：区分连接、认证、模型、重试及等待超时，显示安全的耗时摘要；明确 Hooks 授权与模型生成是不同环节。

## 安装与升级

1. 从托盘退出旧桌宠。
2. 运行新版安装器，沿用原安装目录，无需先卸载。
3. 用原快捷方式启动。个人设置、密钥、位置和自定义角色保留，建议升级前备份个人数据。

`Source code (zip)` 是源码，普通用户请选择安装 EXE。附带 `SHA256SUMS.txt` 和 `INSTALL.txt`。安装包未签名，尚无应用内自动下载更新。

PAC 自动代理脚本暂不自动转换；特殊网络环境可显式配置代理环境变量。新版本不能保证所有模型、代理和服务商的响应速度，遇到问题可导出错误日志反馈，请勿提供密钥或登录文件。
