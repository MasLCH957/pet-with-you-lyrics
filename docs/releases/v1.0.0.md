# pet-with-you 1.0.0

Windows 10/11 x64 桌宠。普通用户下载 **pet-with-you-1.0.0-x64-setup.exe**，双击安装即可；纯桌宠无需另装 Node.js、Git 或 Codex CLI。

## 本次更新

- 改善覆盖升级兼容性，保留个人设置、已保存密钥、字体、位置和自定义角色；补充两版旧安装器的真实升级验证。
- 保留全部 106 段动画及自定义桌宠能力。分离源码与运行包清单，排除开发历史、媒体规划和旧发布材料，原始素材不转码、不降质。
- 减少鼠标穿透状态的重复系统调用，隐藏气泡不再随鼠标移动反复读取布局。反馈者电脑上的鼠标迟滞仍需实机复测。
- 补充 DeepSeek 官方余额配置示例：数字字段为 `balance_infos.0.total_balance`，总额度留空；中转站需使用自己的余额接口。

## 安装与升级

1. 退出旧桌宠，建议先备份个人数据。
2. 运行新版安装器，沿用自动识别的安装目录，无需卸载旧版。
3. 正常启动桌宠，检查设置、尺寸、密钥查询和联动入口。

升级前建议备份个人数据，不要同时运行新旧桌宠，也不要分享包含密钥的数据文件。

附带 `SHA256SUMS.txt` 与 `INSTALL.txt`。当前安装包未签名，尚无应用内自动更新。少数电脑“仅加 --no-sandbox 才能启动”的反馈仍在排查，本版不默认关闭沙箱。
