# pet-with-you 1.1.6

本版在歌词功能基础上补充暂停自动隐藏，并保留 Windows 系统媒体会话、同步歌词和播放控制能力。

## 新增

- 音乐暂停或停止持续 5 秒后自动隐藏歌词卡片，减少暂停期间对桌面的占用。
- 恢复播放时重新显示歌词；暂停期间切换歌曲会取消旧计时并显示新歌。
- 隐藏后不会被状态轮询立即重新弹出。

## 验证

- 161 项自动测试通过。
- Electron 歌词界面回归通过，实际覆盖暂停 5 秒隐藏和恢复播放重现。
- 打包内容审计通过，106 段动画与 142 项原始素材完整。
- 打包后的隔离启动、设置、DPI、联合启动器和元数据检查通过。

## 安装

下载 `pet-with-you-1.1.6-x64-setup.exe`，退出旧版桌宠后运行安装程序即可覆盖升级。个人设置、保存的密钥、位置和自定义角色会保留；升级前仍建议备份用户数据。

安装包未进行代码签名，Windows 可能显示未知发布者。请使用本 Release 中的 `SHA256SUMS.txt` 核对安装包。
